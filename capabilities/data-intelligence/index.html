FAQ

Questions we hear about Analytics & Data.

What is Google Consent Mode v2 and do I need it?

+

Consent Mode v2 tells Google tags whether a visitor has agreed to analytics and advertising storage. For websites with visitors from the EU and EEA it is required to keep using Google advertising features and to measure compliantly.

Can you audit our existing GA4 and GTM setup?

+

Yes. We review data quality, events, conversions, consent configuration and tag governance, then deliver a prioritised list of fixes — and can implement them.

What is a live analytics dashboard?

+

A continuously updated view that combines sources such as GA4, Search Console, advertising platforms and consent status, so you can see performance and problems without building reports manually.
